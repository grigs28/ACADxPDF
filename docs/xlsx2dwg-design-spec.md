# 绿色建筑设计专篇 xlsx → DWG 转换规格

## 图框与布局

| 项目 | 值 | 说明 |
|------|-----|------|
| 模板 | `Template/A1.dwt` | A1 图框 |
| 图框尺寸 | 84100 × 59400 | 1:100 比例（841mm × 594mm） |
| 图框原点 | (0, 0, 0) | 左下角 |
| 有效绘图区 | (2500, 1000) ~ (77100, 58400) | 宽 74600，高 57400 |
| 右侧标题栏 | x: 77100~84100，宽 7000 | |
| 底部标题栏 | y: 0~1000，高 1000 | |
| 列数 | 3 | 均分绘图区，列间留间隙 |
| 标题区域高 | 5000 | 每张图纸顶部，居中写标题 |

## 字高与样式

| 层级 | 内容示例 | 字高 | 样式 | 说明 |
|------|----------|------|------|------|
| 图纸标题 | 绿色建筑设计专篇（建筑）一 / 二 / 三… | **600** | **加粗** | 每张图纸递增，居中于标题区域 |
| 一级标题 | 一、工程概况 / 二、本项目绿色建筑设计情况 / 三、主要绿色技术措施 | **450** | **加粗** | 章节标题 |
| 二级标题 | (一) 设计依据 / (二) 主要绿色技术措施 | **400** | **加粗** | 子章节标题 |
| 正文/表格 | 条款文字、评分表数据、工程信息等 | **350** | 常规 | 其他所有内容 |

## 字体

- 中文：宋体
- 字体编码：134 (GB2312)

## 内容装填规则

1. 标题区域（5000高）写在图纸顶部，剩余区域放内容
2. 内容按 3 列从左到右排列，每列顶部对齐
3. 根据字高 350 和实际行高计算每列可容纳的行数
4. 一列满了换下一列，3 列都满了换下一张图纸
5. 每张新图纸标题的章节号递增（一→二→三…）

## 分页截取规则

- 评分表格（(二) 主要绿色技术措施下方）按条款分组，如 4.2.1、4.2.2 各为一组
- 同一条款的所有行 **不可拆分**：要么全部在当前列，要么整体移到下一列/下一页
- 判断方式：当前列剩余空间 < 该条款所需行数 → 整条移到下一列

## 表格线与合并单元格

- 有边框的单元格 → ACAD TABLE 默认网格线可见
- 无边框的文本区域 → 使用 MTEXT，不使用 TABLE
- 合并单元格 → `vla-MergeCells` 按原 xlsx 合并区域复刻

### 合并单元格

- 共 882 个合并区域
- 最常见：1×2（269个）、1×7（230个）、1×3（101个）、1×19（43个）
- 全宽合并（1×19）：标题行和文本行跨所有 19 列

### 字高分布

| 字高 | 单元格数 | 用途 |
|------|----------|------|

### 列宽

- 所有 19 列宽度一致：8.75 chars

### 行高

- 默认 15pt，非默认行高范围 20pt~210pt
- 评分表区域（166~339）行高变化大：20pt~210pt

## 技术实现

- acad.exe + AutoLISP（vla-AddTable / vla-AddMText / vla-MergeCells）
- LISP 文件编码：GBK
- 分 chunk 处理避免 acad.exe 超时（每 chunk ≤ 60 行）
- 每个独立函数用 `vl-catch-all-apply` 包裹，单 chunk 失败不影响其他

## 输出

- 输出 DWG 2007 格式
- 文件名：`design-doc-{项目号}_{专业}.dwg`
